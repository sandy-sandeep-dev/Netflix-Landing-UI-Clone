# Netflix UI Clone

A responsive Netflix landing page clone built using pure HTML and CSS.

## 🚀 Features
- Responsive design (Mobile + Desktop)
- Clean layout using Flexbox
- Hero section with overlay
- Modern navigation bar
- Styled buttons and input fields

## 🛠 Tech Stack
- HTML5
- CSS3
- Flexbox
- Media Queries

## 📱 Responsive Design
Works smoothly across:
- Mobile devices
- Tablets
- Laptops

## 📌 Purpose
This project was built to practice front-end layout structuring and responsive web design using only HTML and CSS.
